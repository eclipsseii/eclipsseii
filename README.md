## ⭐ Избранные проекты

### [A/B-тест новой формы оплаты](https://github.com/eclipsseii/payment-form-ab-test)
**Вопрос:** стоит ли раскатывать новую форму оплаты ЖКХ?
**Результат:** конверсия в успешную оплату выросла с 65,8% до 80,4% (+14,6 п.п., p < 0,001). Главный прирост дал шаг подтверждения платежа (+9,4 п.п.). Рекомендация: раскатывать.
`Python` `pandas` `statsmodels` `z-тест` `доверительные интервалы` `воронка`

### [Удержание пользователей мобильной игры](https://github.com/eclipsseii/mobile-game-retention-analysis)
**Вопрос:** за счёт чего растёт активная аудитория игры?
**Результат:** рост DAU держится на притоке новых игроков, а не на удержании: к седьмому дню остаётся около четверти пользователей (D1 = 81,9%, D7 = 24,2%). Метрики продублированы в PostgreSQL, собран дашборд в Tableau.
`Python` `PostgreSQL` `Tableau` `retention` `когортный анализ` `DAU/WAU/MAU`

### [Анализ продуктовой воронки интернет-магазина](https://github.com/eclipsseii/product-funnel-analysis)
**Вопрос:** где магазин теряет покупателей?
**Результат:** главная точка потерь — переход «Карточка товара → Корзина»: дальше проходят только 40% пользователей. Сделан разрез по устройствам, источникам трафика и месяцам.
`Python` `SQL` `pandas` `воронка` `сегментный анализ`
